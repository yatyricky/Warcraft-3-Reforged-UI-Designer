# WC3 UI Editor 全新构建计划（本仓库 editor/ 子目录，v1 纯编辑器 + 类型全集）

## 核心决策

- **落点**：本仓库新子目录 `editor/`，独立 Vite 工程（自带 package.json），**不注册 workspaces、不改根 package.json**，不动 legacy `src/ts`、`src/layout`、`.cursor/`。`.gitignore` 追加 `editor/node_modules`、`editor/dist`。
- **技术栈**（按"最适合 agent 开发"标准从零选择）：**React 19 + TypeScript strict + Vite**。理由：训练语料最充分、模式最常规，agent 产出可靠性最高；配套选型：
  - 状态：**zustand + immer**，规范化存储（`frames: Record<id, FrameNode>` + children id 数组）
  - 撤销/重做：**整树快照历史**（结构共享 + 上限 100），取代 legacy 40 个命令类，出错面最小
  - 样式：**Tailwind CSS v4**（样式与组件同址，避免跨文件 CSS 冲突）
  - 层级树：**react-arborist**（拖拽重排/改父/折叠开箱即用，自研 DnD 易出 bug）
  - 测试：**Vitest**；工程文件读写：**File System Access API**（降级下载/上传）+ localStorage 自动暂存
  - 画布：DOM 渲染 + CSS transform 平移缩放（不做全量重排）
- **数据模型对齐 Zulaman-WE 的作者面**：uGUI RectTransform 语义（`anchorMin/anchorMax/anchoredPosition/sizeDelta/pivot`，相对父 frame），不再沿用 legacy 绝对矩形模型。布局引擎为全新自研求解器，公式与 `FrameComponent.cs:204-221`（点锚/拉伸锚）严格一致。
- **坐标系**：war3 全屏 0.8×0.6、原点左下；画布以 1920×1080 16:9 为舞台，标注 4:3 安全区（Frame 族限制）。
- **v1 不做导出**（C# codegen 与 FDF/TOC 留 v2）；类型做**常用全集**。
- UI 语言：中文。

## 数据模型（v1）

- **9 种类型**：`FRAME`（容器）、`IMAGE`（贴图，对应 FrameImage）、`TEXT`、`BUTTON`、`CHECKBOX`、`STATUSBAR`、`SLIDER`、`EDITBOX`、`TEXTAREA`。全部进编辑器模型与画布预览；FRAME/IMAGE 是框架已验证类型，其余预览为简化示意（占位框 + 类型徽标 + 文字/贴图近似渲染），为 v2 导出预铺字段。
- **FrameNode 通用字段**：`id`（内部稳定 id）、`name`（frameName，全局唯一 + war3 合法标识符校验）、`type`、`active`、`visible`、`raycastTarget`、`layout{anchorMin,anchorMax,anchoredPosition,sizeDelta,pivot}`、`children[]`。
- **类型特有字段**：IMAGE `texture`（war3 路径）+ `texturePreviewPath`（本地预览，双轨）；TEXT 族 `text/scale/color/textHorAlign/textVerAlign`；STATUSBAR `value(0-100)`；SLIDER `min/max/value`；EDITBOX/TEXTAREA `text`。
- **工程**：`name`、`schemaVersion`、背景变体（带UI/纯色）、画布 overlay 开关、frames 注册表。

## 布局引擎（core/layout，纯 TS）

- 递归自顶向下求解绝对矩形（父矩形 → 按 anchor 类型套点锚/拉伸锚公式），是画布渲染与命中测试的唯一几何源。
- 交互逆变换：拖动 → 反解 `anchoredPosition`；resize 手柄 → 反解 `sizeDelta`（拉伸锚 → 改 anchor 偏移）；封装成纯函数便于单测。
- **Golden 测试**：用 FrameComponent.cs 的公式与 UiTest 三个验证场景（居中面板/顶部拉伸条/贴角图标）的期望几何做基准。

## 面板功能（v1）

**顶栏（工程信息）**：工程名编辑、新建/打开/保存/另存、自动暂存指示、撤销/重做、缩放百分比与控件、背景变体切换、overlay 开关（安全区/网格）。

**画布**：
- 16:9 舞台 + 4:3 安全区虚线 + 0.8×0.6 游戏区标示；frame 按 DFS 序绝对定位渲染（z 序 = 树序）。
- 选中：点击 / Shift 加选 / 框选（marquee，legacy 没有）；隐藏或失活帧幽灵显示不可交互。
- 变换工具：移动拖拽、8 向 resize 手柄、**pivot 标记**、**Unity 式锚点 gizmo**（min/max 可视化）+ **锚点预设**（9 点 + 4 拉伸 + 居中）。
- 吸附：安全区边缘、网格；键盘：方向键微调（Shift×10）、Del 删除、Ctrl+D 复制、Esc 取消选择。
- 平移：滚轮/空格拖拽；缩放：Ctrl+滚轮对光标缩放。

**Hierarchy（react-arborist）**：树视图、拖拽重排/改父（环检测）、折叠、显隐/失活眼睛图标、点击与 Ctrl 加选（与画布双向同步）、双击重命名。

**Inspector**：
- Frame 组：name/type/active/visible/raycastTarget（+唯一性与合法字符校验提示）。
- Rect Transform 组（仿 Unity）：锚点预设控件、anchorMin/Max、anchoredPosition、sizeDelta、pivot，只读显示解算后的绝对矩形。
- 类型属性组：贴图双轨（路径 + 本地预览文件）、文字/颜色/对齐、进度/滑条数值等。
- 所有编辑走 store action → 快照入历史；输入框 change/blur 一次性提交。

## 持久化

- 新 JSON schema（`schemaVersion`，防御式加载），FS Access API 打开/保存/另存 + 降级下载/上传；localStorage 防抖暂存，重载提示恢复。
- 复制 Zulaman-WE 的 `docs/war3-ui-frame-guide.md` 到 `editor/docs/` 作导出阶段的权威参考。

## 实施阶段（每阶段跑验证）

1. **脚手架**：editor/ Vite+React+TS+Tailwind+zustand+ESLint/Prettier+Vitest；三栏 + 顶栏布局骨架、深色主题。
2. **core 模型与布局引擎**：类型定义、各类型默认预设、规范化树 store、矩形求解器 + golden 测试。
3. **画布渲染**：舞台/安全区/游戏区、按类型渲染、平移缩放、overlay。
4. **选择与变换**：marquee/多选、移动/resize/锚点 gizmo/预设、吸附、快捷键。
5. **Hierarchy**：树、拖拽改父重排、显隐、选择同步。
6. **Inspector**：三组字段、校验、命令提交。
7. **持久化**：schema、FS Access API、暂存恢复、顶栏收尾。
8. **打磨验收**：dev server + 浏览器技能全流程自测（建树→变换→改属性→undo→保存→重载恢复），截图核对，README。

## 验证方式

- `cd editor && npm run build`（tsc + vite build）、`npm test`（Vitest）。
- `npm run dev` 起服务，用浏览器技能实测交互与布局，截图核对。

## 明确不做（v1）

C#/FDF/TOC 导出（v2，C# 优先）、BLP/DDS 解码（本地预览仅 PNG/JPG/WebP）、scrollview/特效组合件（后续按 Zulaman-WE guide 配方参考实现）、按钮多状态视觉模拟、多语言 UI、桌面打包。
